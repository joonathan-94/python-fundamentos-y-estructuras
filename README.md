# Python — Fundamentos y Estructuras de Datos

Repositorio personal de estudio y práctica de Python.

El objetivo es construir una base sólida del lenguaje, mejorar la lógica de programación y comprender las principales estructuras de datos antes de avanzar hacia desarrollo backend con Flask.

Este repositorio también funciona como registro del aprendizaje práctico de Git y GitHub utilizado durante el proceso.

---

## Objetivos

- Consolidar los fundamentos de Python.
- Comprender cómo funciona el lenguaje y no limitar el aprendizaje a memorizar sintaxis.
- Mejorar progresivamente la lógica de programación.
- Estudiar en profundidad las principales colecciones y estructuras de datos.
- Aprender programación orientada a objetos.
- Practicar manejo de archivos, excepciones, módulos y paquetes.
- Introducir testing.
- Desarrollar un gestor de tickets por consola como proyecto integrador.
- Preparar una base técnica suficiente para continuar con Flask y PostgreSQL.
- Practicar Git y GitHub utilizando un flujo de trabajo basado en ramas y Pull Requests.
