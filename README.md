# Python — Fundamentos y Estructuras de Datos

Repositorio personal de estudio y práctica de Python.

El objetivo es construir una base sólida del lenguaje antes de avanzar hacia
desarrollo backend con Flask y posteriormente aplicar los conocimientos
adquiridos en proyectos reales.

## Objetivos

- Repasar y consolidar fundamentos de Python.
- Mejorar la lógica de programación.
- Comprender programación orientada a objetos.
- Aprender estructuras de datos y algoritmos.
- Practicar manejo de archivos, excepciones y módulos.
- Aprender testing.
- Desarrollar un gestor de tickets por consola como proyecto integrador.
- Prepararme para desarrollo backend con Flask.

## Proyecto integrador

Al finalizar los bloques principales se desarrollará un gestor de tickets
por consola utilizando los conocimientos adquiridos durante el estudio.

Posteriormente, estos fundamentos servirán como preparación para estudiar
Flask, PostgreSQL y desarrollo backend.
